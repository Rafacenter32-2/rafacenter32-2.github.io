## Developing

just run  
`npm install`
for install depedencies  
`npm run dev`
open a developer web server to test it

## Building

To create a production version of the website run `npm run build`

You can preview the production build with `npm run preview`.

To deploy the website, you may need to install an [adapter](https://svelte.dev/docs/kit/adapters) for your target environment.
